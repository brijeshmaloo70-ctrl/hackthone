Capabilities

Everything the Care Team Needs

Built around one shared Care Plan — the single source of truth for every agent.

Proactive Check-ins

Asha initiates daily voice/WhatsApp check-ins on her own schedule — no manual trigger needed. She adapts tone and channel based on mood and escalation level.

Trend Detection

MedInsightAgent runs a 7-day rolling analysis every 3 days. Deteriorating trends trigger structured escalation alerts — Level 0 to Level 3 — before a crisis forms.

Smart Family Alerts

ConnectAgent notifies the caregiver with urgency-tiered messages. Critical events fire both WhatsApp and SMS simultaneously. Weekly summaries keep family engaged without alarm fatigue.

Pre-Visit Doctor Briefing

A rich 30-day clinical summary — vitals table, adherence stats, escalation log, and clinical recommendations — auto-generated before every appointment.

Social Wellbeing Tracking

Isolation detected after 3 consecutive days with no social contact. The patient agent nudges reconnection; caregiver is alerted. Social wellbeing score tracked alongside vitals.

Multilingual (Hindi + English)

All patient-facing messages are crafted in real Devanagari Hindi script — not transliterations. Clinician and caregiver interfaces stay in English. True bilingual care.

30-Day Simulation Walkthrough

Watch CareSync AI catch a real deteriorating trend — from stable to critical, and back.

Phase 1 · Days 1–10

✅ Stable Baseline

Asha conducts daily Hindi check-ins. BP ~140/90, glucose ~175 mg/dL, 95% medication adherence. Weekly summary sent to Suresh on Day 7. All agents in green mode.

BP 140/90 Glucose 175 Adherence 95%
Phase 2 · Days 11–20

📈 Gradual Deterioration

BP begins drifting upward (140→155 mmHg). Glucose climbing. Medication adherence drops. MedInsightAgent detects the upward BP trend on Day 14. Adherence alert on Day 19.

BP Trending Up Adherence Dropping Level 1 Escalation
Phase 3 · Days 21–27

⚠️ Dangerous Trend

Day 22: BP 165–175, glucose 280–310 triggers Level 2 escalation. Doctor and family alerted via WhatsApp. Day 24: 5 consecutive isolation days detected — family nudged. Doctor visit preparation begins Day 27.

BP 165–175 Isolation 5d Level 2 Escalation
Phase 4 · Days 28–30

🆘 Critical → Intervention

Day 28: Level 3 critical. Emergency voice call to patient, SMS + WhatsApp to family. Days 29–30: Family visits, vitals begin stabilising. Day 30: Full 30-day pre-visit doctor report generated.

Under the Hood

Built with Production-Grade Tools

🧠

Google Gemini 1.5 Flash

Powers all three agents with context-rich, specialised prompts. Graceful fallback to template mode without an API key.

🗄️

SQLite Memory

Five-table persistent memory — vitals, check-ins, medications, social interactions, events. Month-long patient history.

📡

Pub/Sub Event Bus

Synchronous pub/sub system for agent coordination. Named event types ensure no tight coupling between agents.

🌐

Mock Communication APIs

WhatsApp, voice call, and SMS integrations mocked for demo. Drop-in replaceable with Twilio or Meta's Cloud API.

🔤

Devanagari NLP

Real Hindi messages in Devanagari script, not transliterations. Bilingual template engine with language-aware routing.

📊

Rich Report Generation

30-day clinical summaries with vitals tables, trend flags, adherence stats, and doctor recommendations saved as markdown.
